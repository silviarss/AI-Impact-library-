# About AI Impact Library

## Vision

The AI Impact Library is a structured knowledge base mapping the consequences of Artificial Intelligence across society.

## Purpose

The project aims to document:

- Opportunities created by AI
- Risks introduced by AI
- Ethical considerations
- Stakeholders affected
- Evidence supporting each impact

## Methodology

Each AI impact is documented using a standardized framework including:

- AI capability
- Ethical dimensions
- Polarity
- Stakeholders
- Benefits
- Risks
- Evidence
- References

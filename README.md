# AI-Impact-library

## Welcome

The AI Impact Library is an open knowledge base that documents the impacts of Artificial Intelligence across industries, organizations, and society.

The goal is to create a structured, evidence-based repository where every AI impact is described using the same format, making it easy to explore, compare, and understand.

---

## Mission

Artificial Intelligence is changing every sector of society.

This repository aims to answer questions such as:

- What impact does AI have?
- Who is affected?
- What are the benefits?
- What are the risks?
- Which industries are involved?
- How significant is the impact?

---

## Repository Structure

- `taxonomy/` → Defines how impacts are classified.
- `templates/` → Contains templates for documenting impacts.
- `impacts/` → Contains the documented AI impacts.
